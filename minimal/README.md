# Minimal Milestone 1 website

This single Node.js file includes the Home, Login, and Register pages and their CSS. No packages or build step are needed. It uses sample crowd data and does not create accounts.

Run with Node.js:

```sh
node minimal/server.mjs
```

Open http://localhost:8081. Keep the terminal running. Port 8081 avoids a conflict with an earlier server on port 8080.

To run from another computer on the VM network, use http://VM_PRIVATE_IP:8081 with the VM's actual IP address.
